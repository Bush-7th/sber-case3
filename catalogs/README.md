# Каталог для первого старта

`seed.json` — подготовленные B данные по specs §1.2–1.3 для проверки и импорта разработчиком A. Это **не** замена административному API и не согласованная серверная схема.

Внутри восемь основных видов и отдельное расширение ГИМС, три программы, семь семейств правил. Значения Decimal передаются строками. Неизвестный кадастровый шаблон и спорная привязка суммы помечены `needs_clarification`; отсутствующие значения → UNKNOWN. Условный дефицит всегда warning.

Срок окончания сегодня принимается включительно. ИНН гаранта не сравнивается с ИНН заявителя. Дополнительные ИНН и сумма субсидии извлекаются только при явном наличии и не расширяют формальный минимум.

Порядок operands для `ratio_gte`: собственные средства, общие расходы. `date_compare`: значение документа, `reference_date` из снимка. `required_fields.parameters.fields` — список ключей через запятую. A должен сопоставить эти данные с Pydantic, проверить ссылки/типы/операции и сохранить неизменяемые опубликованные версии.
