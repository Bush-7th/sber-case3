# Тестовая матрица B

Дата: 10.10.2026. Реальные образцы и их производные хранятся вне Git. В текущем checkout они не предоставлены. **Все проверки качества извлечения ниже не выполнены.** DTO контрактных тестов не являются образцами документов.

**BINT01:** 15 браузерных сценариев на конечных DTO CON01 прошли в Edge с одним worker: обе роли, UNKNOWN и severity, 401/503, admin 50→60 с сохранением схем/составных условий/операндов, desktop/phone, вход/reload, восстановление настроек и решения после 409, смена отчёта после подтверждения, неоднозначный повтор решения с исходным телом/ключом, одинаковые имена, file ID/fragment ID, устаревание и листы с пагинацией. 10 типов тестовых ответов дополнительно валидированы настоящими Pydantic DTO backend. Это покрытие интерфейса/контракта, а не документная или сквозная приёмка.

## Совместный прогон после подключения API

| Проверка | Ожидаемый результат | Фактический результат |
| --- | --- | --- |
| Две роли и прямые URL файлов/admin API | Серверный отказ без прав | Не выполнено |
| Создать заявку, выбрать программу/редакцию/контекст | Подтверждённая сервером заявка | Не выполнено |
| Смешанный пакет, большой и малый файл | Быстрый приём; готовый файл виден до конца пакета | Не выполнено |
| Один документ в нескольких файлах, несколько экземпляров | Минимум по DocumentUnit, без смешения организаций | Не выполнено |
| Обязательный и условный дефицит | Error и warning; pending до анализа состава | Не выполнено |
| Own funds 49.99% / 50% / выше | FAIL / PASS / PASS, Decimal на сервере | Не выполнено |
| Нет операнда суммы / разные суммы | UNKNOWN / FAIL, без подставленного нуля | Не выполнено |
| Дата в будущем / срок сегодня / истёкший срок | FAIL / PASS / FAIL; файлы сохранены | Не выполнено |
| ИНН заявителя и отдельный ИНН гаранта | Проверка роли и согласованности | Не выполнено |
| OCR → сохранённый текст → Qwen → UI | Проверяемый источник и различимые стадии | Не выполнено |
| Пустой OCR, timeout, 401 провайдера, плохой JSON | Ошибка соответствующего этапа без успеха | Не выполнено |
| Повтор Qwen после сбоя/перезапуска | Совместимый OCR не вызывается повторно | Не выполнено |
| Изменить тип/группу и дозагрузить | Новая ревизия/извлечение, история не потеряна | Не выполнено |
| Принять / вернуть / отклонить | Автор/причина/revision/report ID отдельно от оценки | Не выполнено |
| Admin 50→60, новый вид/условие, публикация | Новый расчёт на тех же файлах | Не выполнено |
| Перезапуск/lease/поздний результат | Нет потери или устаревшей публикации | Не выполнено |
| External→local, удалённые сервисы недоступны | Реальный локальный вызов без fallback | Не выполнено |
| Новые/закрытые образцы | Оценка по видам, нет подгонки по именам | Не выполнено |

Автоматизированные проверки интерфейса: `frontend/tests/workbench.e2e.ts`. Транспорт: `frontend/src/shared/api/client.test.ts`. Результаты их запуска записываются в collaboration; реальная приёмка требует отдельно заполнить таблицы выше на стенде A+B.
