# Журнал решений

Дата: 10.10.2026. Записи B относятся к текущему frontend; решения server-side из specs пока не подтверждены реализацией.

| Решение | Варианты и выбор | Риск / проверка |
| --- | --- | --- |
| Серверное состояние | Самописный store или TanStack Query → Query по specs, формы отдельно | Ошибки/устаревание должны учитывать revision и run; проверка HTTP DTO |
| API-граница | Разрозненный fetch или один адаптер → `shared/api/client.ts` с Zod | OpenAPI отсутствует; окончательные DTO согласует A |
| Автоматическая оценка и решение | Общее состояние или отдельные сущности → отдельный DecisionPanel с основанием | UI не доказывает backend-права; нужна совместная проверка |
| Обработка ошибок и повтор | Автоматический frontend retry или worker → retry отключён, явная команда повтора | Потеря ответа загрузки требует сохранённого idempotency key |
| Визуальный стиль | Анимации каждой смены данных или спокойное рабочее место → статические polling-обновления, короткий отклик кнопок | Skill emil-design-eng; reduced motion отключает transform, клавиатурный focus без анимации |
| Доставка | Хостинг Sites или локальная SPA → Vite + Nginx в Docker по архитектуре проекта | Docker daemon недоступен для проверки; общий Compose подключает A |
