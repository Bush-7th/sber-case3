# INT01 — передача backend для интерфейса B

10.10.2026. Ветка `backend/INT01`, поверх `backend/LOC01` (`bfd370c`). Frontend не изменён. Схемы и пути OpenAPI 0.2.0 сохранены; обновлено только описание реализации.

## Подключение

Локальный API запущен на `http://127.0.0.1:8000`, отдельный worker — рядом. Для Vite используйте proxy `/api` на этот адрес; запросы с credentials и CSRF остаются обязательными. Origin localhost/127.0.0.1:5173 разрешён в конфигурации демонстрационного запуска. Bootstrap-пользователи: `specialist`, `administrator`; их пароли находятся только в игнорируемом `local-data/int01/demo.env`, права файла 600. Не переносить этот файл в Git или frontend.

Сохранённая отдельная БД `case3_int01_demo` содержит две проверки реальной первой страницы ЕГРН: Ollama CPU (106 секунд) и Qwen (25 секунд), отчёты и решения `needs_revision`. Извлечены кадастровый номер, назначение, адрес с источниками. Недостающие обязательные документы показаны ошибками; неоднозначная кадастровая маска — UNKNOWN. PDF и производные материалы остаются вне Git. Это проверка одного реального образца, не подтверждение всего покрытия.

Перезапуск этих локальных процессов из корня репозитория:

```bash
backend/.venv/bin/dotenv -f local-data/int01/demo.env run -- backend/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
backend/.venv/bin/dotenv -f local-data/int01/demo.env run -- backend/.venv/bin/python -m app.runtime.worker
```

Команды запускаются в отдельных терминалах. Они требуют работающих PostgreSQL на 55439 и Ollama на 11439; это адреса текущего проверочного стенда, не настройки Compose. Для Compose остаются `.env`, внутренние `db`/`ollama` и прежние инструкции runtime.md. Добавлен сервис `worker`. Миграция до `0003_workflow` и `bootstrap` обязательны: bootstrap добавляет три программы, восемь видов и расширение ГИМС, не сбрасывая пароли и опубликованные редакции. Docker daemon здесь недоступен, сборка контейнеров не проверена.

## Работающие операции

| Сценарий | API и поведение |
| --- | --- |
| Вход и каталог | POST/DELETE sessions; после слияния B добавил GET sessions для восстановления пользователя/CSRF; GET programs и versions, три преднастроенные программы |
| Заявки | GET/POST packages; GET detail; видны только собственные заявки специалиста |
| Загрузка | POST files, multipart **`files`** (повторяемое поле) и `expected_revision`; `Idempotency-Key`; оригинал, ревизия и задание сохраняются одной транзакцией, ответ 202 |
| Проверка | POST verification-runs; polling GET run раз в 2 секунды; `preparing/ocr/extracting/validating`, прогресс, отдельная ошибка файла, документы, поля и источники |
| Источник | Авторизованное скачивание оригинала; PDF preview `?page=N` возвращает PNG; изображения — исходное изображение; XLSX sheets — адресованные ячейки и сохранённые значения формул |
| Дозагрузка/контекст | Новая ревизия и снимок; прежний отчёт и решение получают `outdated`; изменение контекста/версии запускает пересчёт |
| Тип | PATCH document-units/{id}/type; сохранённый override и новый модельный анализ. Для нескольких логических документов в одном файле — явный 409, чтобы не менять их все молча |
| Решение | POST decisions отдельно от машинного результата; комментарий, автор, отчёт, ревизия, актуальность; повтор команды не создаёт второе решение |
| Администратор | Создание/изменение черновика, PATCH rules, validate, publish; версии неизменяемы, новые пороги действуют после смены версии заявки |
| Аудит | GET package audit: создание, загрузка, запуск, настройка, тип, решение |

При `409` обновить detail и повторить осмысленную команду с актуальной ревизией и новым ключом. При повторе той же команды после сетевого сбоя использовать прежний ключ и тело. Администратор не получает доступ к оригиналам и заявкам специалиста. Невалидный JSON, отсутствие достоверных цитат и пустой OCR не превращаются в успешный результат.

Worker берёт PostgreSQL-задание через `SKIP LOCKED`, аренда 60 секунд, heartbeat каждые 10 секунд. После остановки просроченное задание подхватывается снова; успешно опубликованные файлы сохраняются. При публикации проверяются lease, текущий run ID и входная ревизия; старый результат остаётся только в старом запуске. OCR сохранён и повторно используется при ошибке/повторе извлечения. Для временных ошибок — до трёх попыток с Retry-After; семантические ошибки автоматически не повторяются. JSON модели и метаданные вызова сохранены отдельно от публичного результата, без секретов.

## Правила и ограничения

Расчёт выполняется на машинных фактах: комплектность с условным warning, минимум полей, даты/сроки, regex, Decimal-доля собственных средств, равенство явно извлечённых сумм и семейство сверки стороны. Отсутствующее/конфликтующее значение — UNKNOWN; деньги не переводятся в float. Начальная доля 0.50, кадастровая маска требует уточнения. Предикаты поддерживают equals/is_true/all/any и неизвестное условие.

Подготовка PDF/JPG/PNG проверена ранее; новые стратегии DOCX/XLSX добавлены, но реальных образцов этих форматов нет, качество не подтверждено. DOC/XLS принимаются и сохраняются, затем получают явную ошибку подготовки; OfficeConverter пока не подключён. Office preview, ручная группировка, сборка одного логического документа из нескольких файлов и D03 остаются впереди. Приёмка изображения локальной моделью ранее не прошла валидацию цитат; успешен локальный анализ нативного PDF. Worker выполняет файлы последовательно, поэтому CPU-пакет может идти долго.

Сжатая реализация хранит DTO-снимки в JSONB и использует общий прикладной мост M15; выделение отдельных репозиториев/сервисов M02/M04/M10 — последующая работа. Семь семейств правил доступны, но все предметные междокументные сценарии ещё не приняты. `/health/live` — проверка доступности API. `/health/ready` честно оставляет `pipeline_ready=false` до полной приёмки модели/конвертера; это не запрет просмотра сохранённых результатов.

Проверки: 156 backend-тестов с настоящим PostgreSQL, Ruff и свежесть OpenAPI; клиентские TypeScript-типы совпадают. Новые тесты проверяют идемпотентность/ревизии, сохранение после перезапуска, роли и владение, ошибку файла, успешный результат, смену типа, возврат просроченной аренды, запрет поздней публикации и границу 49.99/50/50.01. Отдельно проверены реальные HTTP-сценарии Ollama/Qwen, preview и решение. E2E интерфейса B и полный Docker-прогон ожидаются.
